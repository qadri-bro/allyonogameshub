# Yono Games Hub

Game listings website with a React admin dashboard, Express API and MongoDB.

## Run locally

See [the full setup guide](./yono-platform/README.md).

## Deploy

This repository includes a [Render Blueprint](./render.yaml) for deploying the API, website and admin dashboard together. Follow the [Render deployment steps](./yono-platform/README.md#deploy-to-render).

Use fresh production credentials. Do not reuse database credentials or admin passwords that have been shared in chat or stored in a local `.env` file.
